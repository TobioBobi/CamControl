# Triage labels

| Rolle | Label im Tracker | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Muss bewertet werden |
| needs-info | needs-info | Wartet auf weitere Informationen |
| ready-for-agent | ready-for-agent | Vollständig beschrieben, durch einen Agenten umsetzbar |
| ready-for-human | ready-for-human | Erfordert menschliche Umsetzung |
| wontfix | wontfix | Wird nicht umgesetzt |

Wenn ein Skill eine dieser Rollen nennt, das zugehörige Label verwenden.
Ein Label allein ist kein Auftrag zur Implementierung.
